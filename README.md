# Glassmorphism Dashboard

A modern, sleek, and lightweight admin dashboard built entirely with pure HTML and CSS, featuring a stunning futuristic glassmorphism design.

## 🚀 Features
- **Pure HTML & CSS**: No JavaScript, frameworks, or external libraries required.
- **Glassmorphism UI**: Beautiful frosted glass effects combined with animated gradient backgrounds.
- **Multi-page Navigation**: Seamless and working navigation across different sections (Home, Analytics, Projects, Profile, Settings) using standard HTML anchor links.
- **Beginner-Friendly**: Simple, clean, and easily understandable project structure.
- **Deployment Ready**: Fully compatible with static hosting services like GitHub Pages right out of the box.

## 🛠️ Technologies Used
- **HTML5**: For semantic page structure.
- **Vanilla CSS3**: For all styling, flexbox layouts, and CSS animations.

## 📂 Project Structure
```text
Glassmorphism-Dashboard/
├── index.html       # Main dashboard/home view
├── analytics.html   # Analytics statistics page
├── profile.html     # User profile details
├── projects.html    # Projects showcase view
├── settings.html    # User settings and preferences
└── style.css        # Shared stylesheet for consistent design across all pages
```

## 💻 How to Run Locally
Since this project relies solely on native web technologies, no build steps or package installations are necessary!
1. Clone or download this repository to your local machine.
2. Open the `Glassmorphism-Dashboard` folder.
3. Simply double-click `index.html` to open it in your default web browser.
4. **Recommended:** For a better development workflow, open the project in VS Code and run it using the **Live Server** extension.

## 🎨 Customization
You can easily customize the look and feel by tweaking the styles in `style.css`.
- **Background Orbs**: The animated gradient circles are managed by the `.bg1` and `.bg2` classes. Change their `background` colors for different vibes.
- **Glass Effect**: To modify the frosted glass intensity, adjust the `backdrop-filter: blur(20px)` and `background: rgba(255,255,255,0.08)` properties within the `.dashboard` class.
